# Start Here: From-Scratch Fintech Backend Learning Project

## Purpose

Build the project incrementally. Do not paste the completed reference implementation into this workspace.

The completed repository, if you keep it, should live outside this project and remain closed during the initial implementation. Use it later as an answer key only after completing a phase and reviewing your own design.

## Setup

1. Create a new empty project folder.
2. Copy `AGENTS.md` into the project root.
3. Copy the `docs/` templates into the project.
4. Open the folder in Cursor.
5. Start a new Agent chat.
6. Type:

```text
START FROM SCRATCH
```

## Recommended Git discipline

Create one small commit per completed lesson or checkpoint.

Suggested branch strategy:

- Keep `main` stable.
- Use short-lived branches for experiments.
- Use separate branches for optional comparisons such as Gin, gRPC, Redis, Kafka, or Kubernetes.
- Do not mix a learning spike with the baseline implementation.

## Recommended session rhythm

1. Read the lesson.
2. Read 1 to 3 linked sources.
3. Explain the concept back in your own words.
4. Implement the smallest useful increment.
5. Run tests.
6. Ask for review.
7. Record progress.
8. Commit.
9. Continue with `NEXT`.

## Useful mentor commands

```text

```

## Keep the old completed project separate

A reference implementation is useful after you make your own decisions. It is harmful when it becomes a source of copy-paste shortcuts before you understand the domain. Human beings invented take-home learning projects and then immediately searched for ways to avoid learning from them. Resist the tradition.
